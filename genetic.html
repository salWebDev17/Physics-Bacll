📘 រូបមន្តរូបវិទ្យា៖ ឧស្ម័ន

ស្រង់ និងរៀបចំរូបមន្ត ឈ្មោះនិមិត្តសញ្ញា និងការបំបែកខ្នាតតាមចំណុចនីមួយៗ

១ ទំនាក់ទំនងសម្ពាធ ម៉ាសមាឌ និងល្បឿនមធ្យម Pressure & Speed

📌 រូបមន្តសម្ពាធ៖

\[ P = \frac{1}{3} \frac{N}{V} m_0 V_{av}^2 = \frac{2}{3} \frac{N}{V} \left(\frac{1}{2} m_0 V_{av}^2\right) = \frac{2}{3} \frac{N}{V} K_{av} \]

\[ P = \frac{1}{3} \rho V_{av}^2 \]

📋 ឈ្មោះនិមិត្តសញ្ញា និងខ្នាត៖
  • \(P\) ៖ សម្ពាធឧស្ម័ន Pa ឬ N/m²
  • \(m\) ៖ ម៉ាសឧស្ម័ន kg
  • \(m_0\) ៖ ម៉ាសឧស្ម័ន ១ ម៉ូលេគុល kg
  • \(V_{av}\) ៖ ល្បឿនមធ្យម m/s
  • \(K_{av}\) ៖ ថាមពលស៊ីនេទិចមធ្យម J
  • \(N\) ៖ ចំនួនម៉ូលេគុល គ្មានខ្នាត
  • \(\rho\) ៖ ម៉ាសមាឌឧស្ម័ន kg/m³

២ ការបំបែកខ្នាតសម្ពាធ និងពហុគុណ Pressure Conversions

📌 សម្ពាធបរិយាកាស៖

\[ P = 10^5\text{ Pa} = 1\text{ atm} = 760\text{ mmHg} \]

📌 ពហុគុណនៃ បាស្កាល់ (\(Pa\))៖

\[ 1\text{ kPa} = 10^3\text{ Pa} \]

\[ 1\text{ MPa} = 10^6\text{ Pa} \]

\[ 1\text{ GPa} = 10^9\text{ Pa} \]

\[ 1\text{ TPa} = 10^{12}\text{ Pa} \]

៣ សមីការឧស្ម័នបរិសុទ្ធ និងថេរ Ideal Gas Law

📌 រូបមន្ត៖

\[ PV = N k_B T \]

\[ PV = n R T \]

📋 តម្លៃថេរ និងខ្នាត៖

\(k_B\) ៖ ថេរ Boltzmann \(= 1.38 \times 10^{-23}\text{ J/K}\)

\(N_A\) ៖ ចំនួនអាវ៉ូហ្គាដ្រូ \(= 6.23 \times 10^{23}\text{ mol}^{-1}\)

\(R\) ៖ ថេរឧស្ម័នបរិសុទ្ធ \(= N_A \times k_B = 8.31\text{ J/(mol·K)}\)

៤ សមីការភាពនៃឧស្ម័ន Gas Laws

📌 រូបមន្តទូទៅ៖

\[ \frac{P_1 V_1}{T_1} = \frac{P_2 V_2}{T_2} \]

ច្បាប់សាល (\(P\) ថេរ)៖

\[ \frac{V_1}{T_1} = \frac{V_2}{T_2} \]

ច្បាប់ប៊យ (\(T\) ថេរ)៖

\[ P_1 V_1 = P_2 V_2 \]

ច្បាប់គេលុយសាក់ (\(V\) ថេរ)៖

\[ \frac{P_1}{T_1} = \frac{P_2}{T_2} \]

៥ រូបមន្តបន្ថែមសម្រាប់គណនាបរិមាណឧស្ម័ន Additional Formulas

ចំនួនម៉ូល៖

\[ n = \frac{m}{M} = \frac{V}{V_m} \]

ចំនួនម៉ូលេគុល៖

\[ N = n N_A = \frac{m}{m_0} \]

ម៉ាស ១ ម៉ូលេគុល៖

\[ m_0 = \frac{M}{N_A} \]

ម៉ាសមាឌ៖

\[ \rho = \frac{m}{V} \]

៦ ថាមពលស៊ីនេទិចនៃឧស្ម័ន Kinetic Energy

📌 ថាមពលស៊ីនេទិចមធ្យមនៃ ១ ម៉ូលេគុល (\(K_{av}\))៖

\[ K_{av} = \frac{3}{2} k_B T \quad \text{(J)} \]

📌 ថាមពលស៊ីនេទិចសរុបនៃ \(N\) ម៉ូលេគុល (\(K\))៖

\[ K = N K_{av} = \frac{3}{2} N k_B T = \frac{3}{2} PV = \frac{3}{2} n RT \]

៧ ល្បឿនមធ្យម ឬល្បឿនប្រសិទ្ធភាព Average Speed

📌 រូបមន្ត៖

\[ V_{av} = \sqrt{\frac{3 k_B T}{m_0}} \]

\[ V_{av} = \sqrt{\frac{3 R T}{M}} \]

  • \(V_{av}\) ៖ ល្បឿនមធ្យម m/s
    • 📚 ចុចត្រង់នេះដើម្បីអនុវត្ត
